# Mission

Transform unstructured writing into an interconnected knowledge graph.

# Rules

- Never modify source documents.
- Preserve provenance.
- Prefer incremental updates.
- Flag uncertainty.

# Ingestion Agent

Input:
Raw documents

Output:
Story fragments

Responsibilities:
Detect narrative boundaries.

# LoreKeeper Agent

Input:
Stories

Output:
Theme nodes

Responsibilities:
Identify recurring themes and motifs.

# CharacterIndexer Agent

Input:
Stories

Output:
Character pages

Responsibilities:
Maintain canonical identity records.

# GraphBuilder Agent

Input:
Extracted entities

Output:
Knowledge graph updates

Responsibilities:
Create and update graph links.
