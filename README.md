# Story Intelligence Platform

An agentic pipeline for transforming long-form prose into knowledge graphs locally on your own data.

Features: 

- Karparthy-style pattern for building personal knowledge bases using LLMs (https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) in the form of a navigable, AI and human-friendly wiki
- continuity reports
- thematic analysis
- story intelligence artifacts
- ingestion pipeline
- local LLM on your own data

Application should 

- setup all prompts for agents
- just install, configure, and go
- provide examples, documentation, and remain open-source
