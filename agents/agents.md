# Mission

Transform unstructured writing into an interconnected knowledge graph.

# Rules

- Never modify source documents.
- Preserve provenance.
- Prefer incremental updates.
- Flag uncertainty.

See also [Agent Rules](../rules/agent-rules.md)

# Character Agent

Input:
Stories

Output:
Character pages

Responsibilities:
Maintain canonical identity records.

# Ingestion Agent

Input:
Raw documents

Output:
Story fragments

Responsibilities:
Detect narrative boundaries.

# Historian Agent

Input:
Stories

Output: 
History pages

Responsibilities: 
Maintain canonical history and timeline(s)

# LoreKeeper Agent

Input:
Stories

Output:
Theme nodes

Responsibilities:
Identify recurring themes and motifs.
